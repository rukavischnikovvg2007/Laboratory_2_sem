# Data Dictionary — Словарь данных

## Витрина: ВВП Германии (mart_world_bank)

**Назначение:** Анализ динамики ВВП на душу населения в Германии за 1960-2025 годы

**Гранулярность:** одна строка = одно значение ВВП для Германии за один год

**Обновление:** по мере публикации новых данных World Bank

---

## Описание полей

### 1. `year` (Год)
| Свойство | Значение |
|----------|----------|
| **Тип** | целое число (`int64`) |
| **Nullable** | Нет |
| **Описание** | Год наблюдения |
| **Диапазон** | 1960 — 2030 |
| **Пример** | 2024 |

### 2. `value` (ВВП на душу населения)
| Свойство | Значение |
|----------|----------|
| **Тип** | число с плавающей точкой (`float64`) |
| **Nullable** | Да (если данные ещё не опубликованы) |
| **Описание** | Валовой внутренний продукт на душу населения в текущих долларах США |
| **Единица измерения** | доллары США (текущие) |
| **Диапазон** | 0 — 100,000 |
| **Пример** | 56103.73 (2024 год) |

### 3. `country_iso3` (Код страны)
| Свойство | Значение |
|----------|----------|
| **Тип** | строка (`object`) |
| **Nullable** | Нет |
| **Описание** | ISO 3166-1 alpha-3 код страны |
| **Формат** | 3 буквы |
| **Пример** | DEU, DE |

### 4. `country_name` (Название страны)
| Свойство | Значение |
|----------|----------|
| **Тип** | строка (`object`) |
| **Nullable** | Нет |
| **Описание** | Английское название страны |
| **Пример** | Germany |

### 5. `indicator_code` (Код индикатора)
| Свойство | Значение |
|----------|----------|
| **Тип** | строка (`object`) |
| **Nullable** | Нет |
| **Описание** | Код показателя в базе World Bank |
| **Формат** | латинские буквы и точки |
| **Пример** | NY.GDP.PCAP.CD |

### 6. `indicator_name` (Название индикатора)
| Свойство | Значение |
|----------|----------|
| **Тип** | строка (`object`) |
| **Nullable** | Нет |
| **Описание** | Полное название показателя на английском |
| **Пример** | GDP per capita (current US$) |

### 7. `country_name_full` (Полное название страны)
| Свойство | Значение |
|----------|----------|
| **Тип** | строка (`object`) |
| **Nullable** | Нет |

### 8. `region` (Регион)

|----------|----------|

|----------|----------|

| Свойство | Значение |
|----------|----------|

| Свойство | Значение |
|----------|----------|

## KPI (Ключевые показатели)

| KPI | Формула | Пояснение | Единица измерения |
|-----|---------|-----------|-------------------|
| **Средний ВВП** | `AVG(value)` | Среднегодовой ВВП за весь период | доллары США |
| **Максимальный ВВП** | `MAX(value)` | Пиковое значение ВВП | доллары США |
| **Минимальный ВВП** | `MIN(value)` | Минимальное значение ВВП | доллары США |
| **Темп роста** | `(value_now / value_prev - 1) * 100` | Процентный рост между годами | проценты |
