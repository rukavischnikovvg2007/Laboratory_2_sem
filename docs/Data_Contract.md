# Data Contract — Описание данных

## Источник данных (API)

| Параметр | Значение |
|----------|----------|
| **Название** | World Bank Open Data API |
| **Вариант** | 10 |
| **Тема** | Макроэкономика (Германия: ВВП на душу населения) |
| **Базовый URL** | `https://api.worldbank.org/v2` |
| **Эндпоинт** | `/country/DEU/indicator/NY.GDP.PCAP.CD` |
| **HTTP-метод** | GET |
| **Формат ответа** | JSON |
| **Параметры запроса** | `format=json`, `per_page=20000` |
| **Частота обновления** | Ежеквартально (по данным Всемирного банка) |
| **Ограничения** | Нет строгих лимитов, рекомендуется не более 1–2 запросов в секунду |

---

## Структура сырых данных (raw)

Ответ API World Bank представляет собой список из двух элементов:

1. **Метаданные** (информация о запросе, статистика)
2. **Массив записей** — каждая запись содержит:

```json
{
  "indicator": {"id": "NY.GDP.PCAP.CD", "value": "ВВП на душу населения (текущие долл. США)"},
  "country": {"id": "DE", "value": "Германия"},
  "date": "2023",
  "value": 52700.5,
  "unit": "",
  "obs_status": "",
  "decimal": 0
}

```
## Нормализованный слой (normalized)

### Зерно таблицы
Одна строка = одно значение ВВП на душу населения для Германии за один год

### Схема данных (normalized)

| Поле | Тип | Nullable | Описание | Источник в raw JSON |
|------|-----|----------|----------|---------------------|
| year | int | No | Год наблюдения | `date` |
| value | float | Yes | ВВП на душу (текущие долл. США) | `value` |
| country_iso3 | string | No | Код страны (DEU) | `country.id` |
| country_name | string | No | Название страны | `country.value` |
| indicator_code | string | No | Код индикатора | `indicator.id` |
| indicator_name | string | No | Название индикатора | `indicator.value` |

## Data Quality правила (Неделя 8)

### Проверки качества данных

| № | Правило | Слой | Критичность | Описание |
|---|---------|------|-------------|----------|
| 1 | Таблица не пустая | mart | FAIL | Таблица должна содержать хотя бы одну строку |
| 2 | Нет NULL в year | mart | FAIL | Год не может быть пустым |
| 3 | Нет NULL в country_iso3 | mart | FAIL | Код страны не может быть пустым |
| 4 | Нет NULL в indicator_code | mart | FAIL | Код индикатора не может быть пустым |
| 5 | NULL в value | mart | WARNING | Пропуски в value допустимы (2025 год) |
| 6 | Уникальность бизнес-ключа | mart | FAIL | Комбинация (year, country_iso3, indicator_code) должна быть уникальной |
| 7 | Диапазон year | mart | FAIL | Год должен быть в диапазоне 1960-2030 |
| 8 | Диапазон value | mart | FAIL | ВВП должен быть в диапазоне 0-100000 |
| 9 | Тип year | mart | WARNING | Должен быть int |
| 10 | Тип value | mart | WARNING | Должен быть float |
| 11 | Нет отрицательных value | mart | FAIL | ВВП не может быть отрицательным |

### Бизнес-ключ
`year` + `country_iso3` + `indicator_code`
