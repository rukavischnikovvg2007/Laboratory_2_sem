# Data_Contract
# Описание данных (Data Contract)

## Источники данных (будут уточнены)
- Возможные источники: Kaggle, открытые API, данные с курса
- Данные будут храниться в папке `/data`
- Сырые данные: `/data/raw/`
- Обработанные данные: `/data/processed/`

## Требования к данным
- Отсутствие пропусков в ключевых колонках
- Единый формат времени (ISO 8601)
- Размер файла не более 100 МБ
- Данные должны быть анонимизированы (без личной информации)

## Обновление документа
Этот документ будет обновлён, когда:
- Будет утверждена схема данных
- Появятся новые требования к обработке данных
