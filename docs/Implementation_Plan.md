### Детали реализации
- **Источник данных**: World Bank API
- **Страна**: Германия (ISO3: DEU)
- **Индикатор**: NY.GDP.PCAP.CD (ВВП на душу населения в текущих долларах США)
- **Формат ответа**: JSON
- **Обработка ошибок**: проверка HTTP-статуса, timeout 30 секунд
- **Сохранение данных**: каждый запуск создаёт новый файл с временной меткой (история не перезаписывается)

### Планируемые метрики (KPI)
- Последнее доступное значение и год
- Изменение за 10 лет
- Среднее значение за последние 10 лет
- Год максимума и минимума (без NULL)

### Правила качества данных (DQ)
- Год в разумных пределах (≥ 1960 и ≤ текущий)
- Учёт NULL-значений
- Запрет дубликатов по (country, indicator, year)
