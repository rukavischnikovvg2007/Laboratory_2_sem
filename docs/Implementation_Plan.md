## Схема данных (три слоя)

### 1. RAW слой (сырые данные)
- **Назначение:** исходный ответ API без изменений
- **Формат:** JSON
- **Путь:** `data/raw/variant_10/`
- **Особенности:** 
  - Содержит метаданные и данные в одном списке
  - Вложенные структуры (country, indicator)
  - Не пригоден для прямого анализа

### 2. NORMALIZED слой (нормализованные данные)
- **Назначение:** табличный слой после разворачивания JSON
- **Формат:** CSV
- **Путь:** `data/normalized/variant_10/`
- **Структура:**
  - year (int) - год наблюдения
  - value (float) - значение ВВП
  - country_iso3 (str) - код страны
  - country_name (str) - название страны
  - indicator_code (str) - код индикатора
  - indicator_name (str) - название индикатора
- **Зерно:** одна строка = одно значение показателя для одной страны за один год

### 3. MART слой (витрина данных)
- **Назначение:** подготовленная аналитическая таблица
- **Формат:** CSV
- **Путь:** `data/mart/variant_10/`
- **Витрины:**
  
  **Годовая витрина (mart_yearly_*.csv)**
  - Все колонки из normalized
  - Обогащенные данные из справочника (region, income_group, currency, capital)
  - Временные признаки (date, decade)
  
  **Декадная витрина (mart_decade_*.csv)**
  - Агрегация по десятилетиям
  - Метрики: средний, мин, макс ВВП за десятилетие
  
  **KPI сводка (mart_kpi_*.csv)**
  - Ключевые показатели в одной таблице

### Зачем нужны три слоя

| Слой | Зачем | Кто использует |
|------|-------|----------------|
| RAW | Сохранить исходные данные для пересчета | Только скрипты загрузки |
| NORMALIZED | Иметь чистые данные для разных анализов | Аналитики, разные задачи |
| MART | Быстрый ответ на конкретные вопросы | Дашборды, отчеты, презентации |

**Почему нельзя всё в одном файле:**
1. RAW нельзя менять - это единственный источник истины
2. NORMALIZED переиспользуется для разных витрин
3. MART оптимизирован под конкретные вопросы
4. Разделение упрощает отладку и обновление
