# Правила использования LLM в аналитике

## Можно:
1. Интерпретировать уже рассчитанные метрики
2. Формулировать выводы и риски
3. Предлагать гипотезы причин изменений
4. Предлагать следующие шаги для анализа
5. Помогать со структурой отчёта
6. Объяснять ограничения данных

## Нельзя без проверки кодом:
1. Считать максимум, минимум, среднее, сумму
2. Находить топ-N (топ-5, топ-10)
3. Считать корреляцию или любые другие статистики
4. Определять аномалии
5. Делать любые численные вычисления
6. Придумывать цифры, которых нет в контексте

## Принципы:
- LLM — интерпретатор, а не калькулятор
- Все числа считает код, LLM их только комментирует
- Если данных не хватает — LLM должен сказать "недостаточно данных"
