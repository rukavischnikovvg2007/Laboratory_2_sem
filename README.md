# Laboratory_2_sem

Описание моего первого проекта по анализу данных.

## Как запустить проект (Windows)

1.  Убедитесь, что у вас установлена Anaconda.
2.  Откройте командную строку (cmd) или PowerShell.
3.  Перейдите в папку с проектом. Например:
    `cd C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\Desktop\my_data_project`
4.  Запустите главный установочный скрипт одной командой:
    `scripts\setup_env.bat`
5.  Скрипт сам создаст окружение, установит библиотеки и проверит работу.

## Smoke test

После выполнения скрипта вы увидите сообщение `[ok]` или `[ERROR]`. Если всё хорошо, значит проект готов к работе.
